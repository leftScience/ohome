## 功能概览



### 资源搜索

- 基于 pansou 的网盘资源聚合搜索，支持多搜索源插件
- 搜索结果支持复制分享链接、一键转存



### 转存

- 手动转存支持填写分享链接、提取码和保存路径
- 自动转存 / 定时同步，支持每天、每周规则
- 转存 / 同步完成后推送站内消息



### 任务中心

- 统一管理转存任务与自动同步任务
- 支持任务搜索、状态筛选、执行详情、去同步和删除
- 任务执行记录与失败原因回显



### 播放与阅读

- 影视、短剧、播客 / 有声书等资源浏览与在线播放
- 视频播放器支持全屏、倍速、字幕、音轨、跳过片头片尾和投屏
- 短剧播放器支持选集、连续播放和手势控制
- 播客 / 有声书音频播放，支持后台播放、定时关闭和断点续播
- EPUB / TXT / PDF 电子书阅读，保留阅读进度
- 播放历史记录与首页最近观看回显



### 资源发现

- 热门推荐：豆瓣实时榜单（电影、电视剧）、短剧榜单、听书榜单
- 榜单支持分页加载，点击条目可直接联动全网资源搜索
- 搜索资源、消息提醒和播放历史一屏直达



## 快速上手

下载客户端，直接注册新账户，进行使用，此时你使用的夸克账号是开发者提供的夸克账号。此账号可能是多人共用的，仅供体验。如果你需要独享自己的账号，则需要去设置页面打开独享功能在此登录你的夸克账号，这个时候你的数据就和其他人进行了隔离。  
[下载地址](https://github.com/leftScience/wpan/releases)  请下载 app 开头的**Releases资源**

## 服务端

对于数据安全比较敏感的朋友可以自建服务端，推荐 docker 的方式启动

#### 快速启动（docker run）

```bash
mkdir -p /opt/wpan/conf /opt/wpan/data /opt/wpan/log

docker run -d --name wpan-server --restart unless-stopped -p 18090:18090 --add-host host.docker.internal:host-gateway -v /opt/wpan/conf:/app/conf -v /opt/wpan/data:/app/data -v /opt/wpan/log:/app/log hanlinwang0606/ohome:runtime-v2026.11.03
```



#### 独立运行包（Windows / macOS / Linux）

下载对应平台的独立运行包并解压，首次启动请运行 `launcher`（不要直接运行 `server`），后续 App 可通过“关于wpan”页触发后端拉取最新二进制并自动重启服务。
 [下载地址](https://github.com/leftScience/ohome/releases)  请下载 server 开头的**Releases资源**

### 客户端如何连接服务端

客户端和服务端配合使用，推荐连接顺序如下：

1. 先确认服务端已经启动
2. 手机和服务端尽量处于同一局域网
3. 在客户端登录页优先使用局域网发现
4. 如果自动发现失败，手动输入服务端地址，例如 `http://catx.top:18090`
